# BBC News Clone made for LevelUp Vibe Hackathon

A modern, responsive clone of the BBC News website built with HTML, CSS, and JavaScript.

## Keyboard Navigation

The website supports the following keyboard shortcuts (all using the Alt key as a modifier):

- `Alt + H` - Navigate to Home ✅
- `Alt + P` - Navigate to Profile ✅
- `Alt + Up Arrow` - Scroll to top ✅
